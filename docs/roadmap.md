## MVP — 三端同步 + Web GUI ✅（已交付，待验收）

## 可信内核（阶段 A+B，2026-10 完成）✅
对应《项目缺陷与优化分析报告》阶段 A/B 的 P0/P1 修复，全部落地并通过验收测试：

- [x] P0-1 单路径决策矩阵（删除场景不再同时生成复制+删除）
- [x] P0-2 动作失败时不提交快照，保留上次成功基线
- [x] P0-3 原子写协议（临时文件 + fsync + hash 校验 + rename）
- [x] P0-4 全局运行锁（并发同步 409；执行中拒绝改配置）
- [x] P1-1 角色驱动 backup 拓扑（mirror 仅 peer；backup 恰 1 source + N target）
- [x] P1-2 不可变计划（plan ID + 文件状态指纹，消除 TOCTOU）
- [x] P1-3 路径合法性校验（相同/嵌套/系统根目录拒绝）
- [x] P1-4 符号链接显式跳过，不越出同步根
- [x] P1-5 大小写冲突检测并中止
- [x] P1-6 冲突副本归档到 .miaosync/conflicts/
- [x] P1-7 每节点每轮只扫描一次（预览指纹缓存复用）
- [x] P1-8 快照损坏检测（返回错误而非静默覆盖）

**验收结果（2026-10-10）**：`go test ./...`、`go test -race ./...`、`go vet`、`gofmt`、`go build` 全绿；
12 项验收测试 10 项通过，2 项（大小写冲突/符号链接）在 Windows 上按平台条件跳过（在大小写敏感 FS 与 macOS/Linux 上生效）。
