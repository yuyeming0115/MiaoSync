## 节点路径「选择文件夹」按钮（用户：打开网页后只能手贴路径，能否加按钮点选文件夹）
- 方案：Web 浏览器安全限制下拖入/选文件夹**拿不到本地绝对路径**，所以走 Go 单 exe 原生对话框才是正解。新增 `POST /api/pick-folder`，后端按平台弹系统文件夹选择框返回绝对路径：
  - Windows：`powershell.exe -NoProfile -NonInteractive -WindowStyle Hidden -STA -Command` 调 `System.Windows.Forms.FolderBrowserDialog`（ShowNewFolderButton=$true）；
  - macOS：`osascript -e 'POSIX path of (choose folder ...)'`；Linux：`zenity --file-selection --directory`；
  - `context.WithTimeout(5min)` 兜底；用户取消→空 path（返回 200 不报错）。
- 新增 `internal/web/pickfolder.go`；`server.go` 注册 `/api/pick-folder`。
- 前端：每个节点的 Windows/macOS 路径输入行右侧加 📁 浏览按钮（`.browse`），点 `postJSON('/api/pick-folder')` 回填 input 并同步 `state.config.nodes[i][field]`；点击期间按钮显示"…"禁用。样式 `.node .path-row`/`.node .browse`（青绿描边、hover 上浮）。
- 重编 `miaosync.exe`（09:28，含浏览按钮，windowsgui 无黑窗）；`go build ./...` 与 `go vet` 通过。
